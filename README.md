# Council Simulator

A small Python simulation that tracks the members and leadership of a fictional 42-seat Council over time.

The simulation begins in **Year 1000**. Each year, council members' terms progress, vacant seats are filled with randomly generated names, and the Speaker and High Minister may face votes on whether they should remain in office.

## Requirements

- Python 3
- The [`tabulate`](https://pypi.org/project/tabulate/) package

## Run

In a terminal or any Python platform, run the file `Lottocracy.py`.

The program displays the council for the current year. Enter `0` to stop the simulation. Enter anything else to advance to the next year.
